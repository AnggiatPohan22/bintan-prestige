# UI Rules

## Laravel Blade
- Use existing layouts.
- Use partials/components.
- Do not duplicate header/footer.
- Do not remove existing sections.

## Tailwind
- Prefer reusable classes.
- Avoid inline style.
- Keep mobile responsive.
- Use consistent spacing.

## Admin Components
Recommended components:
- Stat card
- Content card
- Quick action card
- Badge
- Table wrapper
- Form input
- Sidebar item
