# Laravel Boost Workflow Skill

## Main Goal
Use Laravel Boost as the Laravel knowledge layer for AI-assisted development.

## Rules
- Before changing Laravel code, check the installed Laravel version.
- Use Laravel Boost documentation search when available.
- Prefer current official Laravel docs over random blog tutorials.
- Use project-aware inspection before editing:
  - routes
  - models
  - controllers
  - migrations
  - views
  - logs
  - database relationships
- Do not guess Laravel syntax when Boost/docs can verify it.

## AI Workflow
1. Inspect existing structure.
2. Identify affected files.
3. Explain planned changes.
4. Apply minimal changes.
5. Run tests or recommend exact tests.
6. Update docs.
7. Produce implementation report.
