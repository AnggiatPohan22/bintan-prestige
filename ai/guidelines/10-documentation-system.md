# Documentation System Guideline

## Main Goal
Keep documentation useful, current, and safe without deleting historical context.

## Required References
- Master rule: `AGENTS.md`
- Related skill: `documentation-skill.md`
- Related guidelines: all `ai/guidelines/*` files relevant to the task

## Rules
- Update documentation after every meaningful change.
- Do not delete existing docs.
- Do not move docs to `docs/_legacy/` without approval.
- Preserve useful old information by linking or summarizing it.
- Keep canonical docs clear and easy to scan.
- Include rollback notes for meaningful changes.

## Recommended Docs Areas
- `docs/README.md`
- `docs/architecture/`
- `docs/database/`
- `docs/modules/`
- `docs/frontend/`
- `docs/admin/`
- `docs/security/`
- `docs/performance/`
- `docs/seo/`
- `docs/qa/`
- `docs/changelog/`

## Documentation Report Fields
- What changed
- Why changed
- Files changed
- Database impact
- Route impact
- Frontend impact
- Backend impact
- Security impact
- Testing result
- Rollback note
