# Admin Dashboard Skill

## Main Goal
Make the admin dashboard clean, modern, usable, and scalable.

## Rules
- Admin UI must be clear for non-technical users.
- Use consistent form layout.
- Use compact cards for repeatable data.
- Use clear validation messages.
- Use confirmation for destructive action.
- Use preview for frontend-related content.
- Use status badges.
- Use filters and search for listing pages.
- Use pagination for large data.

## Admin UX Principles
- User should know what to do next.
- Required fields must be clear.
- Save/Cancel actions must be obvious.
- Avoid long forms when sections can be separated.
- Use tabs/sections for product detail modules.
