# Frontend Skill

## Main Goal
Build premium, modern, fast, and responsive frontend UI for Bintan Prestige.

## Brand Direction
- Luxury travel
- Premium taxi/tour/activity experience
- Clean black, gold, white, soft gray
- Spacious layout
- Elegant typography
- Smooth animation

## Rules
- Use TailwindCSS only.
- Use Blade components and partials.
- No inline CSS unless unavoidable.
- Mobile first.
- Keep layout clean and readable.
- Use prepared backend data only.
- Use semantic HTML.
- Optimize image rendering.
- Use lazy loading for below-the-fold images.
- Avoid heavy JavaScript.

## Required Components
- Hero
- Booking CTA
- Product cards
- Destination cards
- Review section
- FAQ section
- CTA banner
- Breadcrumb
- Empty state
- Loading state
- Error state

## Visual Rules
- Use consistent spacing.
- Use max-width containers.
- Use subtle shadows.
- Use rounded cards.
- Use smooth hover transitions.
- Avoid generic AI layout.
