# SEO & AI Discovery Skill

## Main Goal
Make the CMS discoverable by search engines and AI search systems using ethical, technical, and content-first SEO.

## Scope
- Google Search
- Google AI Overviews / AI Mode
- ChatGPT Search
- Bing/Copilot search visibility
- General AI answer engine readiness

## Core SEO Rules
Every public page must support:
- meta title
- meta description
- canonical URL
- Open Graph
- Twitter/X card
- robots meta
- sitemap inclusion
- clean slug
- breadcrumb
- semantic H1/H2 structure
- optimized image alt text
- internal linking

## Structured Data
Use JSON-LD where relevant:
- Organization
- LocalBusiness / TravelAgency
- Product / Service
- FAQPage
- BreadcrumbList
- Review
- ImageObject
- WebSite
- WebPage

## AI Search Readiness
- Content must be crawlable.
- Important content must be visible in HTML, not hidden only in JS.
- Use clear sections and headings.
- Use concise answer blocks for FAQs.
- Add first-hand travel insights.
- Add destination-specific pages.
- Add product-specific detail pages.
- Add business identity pages.
- Add author/editor or company credibility signals.
- Maintain sitemap.xml and robots.txt.
- Allow useful crawlers where visibility is desired.

## ChatGPT Search
- Review robots.txt.
- Allow OAI-SearchBot if the goal is ChatGPT Search visibility.
- Do not expose private/admin routes.

## Google AI Search
- Follow normal Google SEO best practices.
- Do not rely on llms.txt for Google.
- Do not create fake mentions or spam pages.
- Avoid mass AI-generated thin content.

## CMS SEO Fields
Admin should manage:
- SEO title
- SEO description
- canonical URL
- OG image
- schema type
- index/noindex
- sitemap priority
- FAQ schema toggle
