# Product Management Skill

## Main Goal
Make product management scalable and easy from admin.

## Product Data
- category
- destination
- name
- slug
- thumbnail
- gallery
- short description
- full description
- meeting point
- duration
- WhatsApp number
- prices
- features
- FAQs
- itineraries
- notes
- status
- featured flag
- SEO meta

## Rules
- Product create/edit must be clear.
- Related data should be managed safely.
- Product cannot break frontend if optional fields are empty.
- Published products only appear on frontend.
