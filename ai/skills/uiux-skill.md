# UI/UX Skill

## Main Goal
Make the public site feel premium and the admin dashboard feel clear, efficient, and trustworthy.

## Public Frontend UX
- Mobile-first layout.
- Clear travel-focused hierarchy.
- Premium spacing and typography.
- Strong booking/WhatsApp CTA placement.
- Visible prices, duration, meeting point, itinerary, notes, and FAQs.
- Clear image alt text and semantic headings.
- Lightweight animation that does not slow the page.

## Admin UX
- Clear create/edit/list flows.
- Obvious Save/Cancel actions.
- Helpful validation messages.
- Filters, search, status badges, and pagination for lists.
- Confirmation before destructive actions.
- Compact repeatable modules for prices, images, features, FAQs, itineraries, and notes.

## Safety
- Do not rebuild UI from zero without approval.
- Do not mix public luxury styling into admin CMS styling.
- Do not hide important content behind JavaScript-only interactions.
- Do not let text, buttons, images, or cards overlap on mobile or desktop.
