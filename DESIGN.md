# Bintan Prestige Design System

## Brand Direction
Luxury tour and travel website for Bintan.

## Public Frontend Style
- Premium
- Black and gold
- Large travel imagery
- Elegant typography
- Clean spacing
- Soft animation

## Admin Dashboard Style
- Modern SaaS
- Light background
- White cards
- Indigo / purple primary color
- Soft gold accent
- Rounded cards
- Clean widgets

## Fonts
- Heading: Cinzel
- Body: Montserrat

## Avoid
- Generic Bootstrap style
- AdminLTE look
- Too many colors
- Hardcoded dummy content
