# Bintan Prestige AI Agent Rules

This is an existing Laravel + TailwindCSS project.

## Critical Safety Rules
- Do not delete existing features.
- Do not change database schema unless approved.
- Do not modify migrations unless approved.
- Do not rename routes, controllers, models, or variables.
- Do not replace existing backend logic.
- Do not hardcode data if database data already exists.
- Before editing, list all files that will be changed.
- Work section by section, not full-project rewrite.

## UI Implementation Rules
- Use TailwindCSS only.
- Use reusable Blade components.
- Keep frontend and admin design separated.
- Public frontend uses luxury travel style.
- Admin dashboard uses modern SaaS dashboard style.
