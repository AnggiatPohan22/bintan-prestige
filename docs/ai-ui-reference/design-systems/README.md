# Design System References

Use these references only as UI inspiration, not direct code copy.

## Inspired By
- Linear: clean layout, sharp hierarchy, minimal SaaS dashboard
- Stripe: professional spacing, strong typography, polished cards
- Vercel: simple black/white premium feel
- Airbnb: travel-friendly imagery, trust sections, clean booking flow
- Notion: readable content layout

## Rules
- Do not copy exact design.
- Adapt to Laravel Blade + TailwindCSS.
- Keep UI consistent with DESIGN.md.
- Use reusable components.
- Avoid adding unnecessary packages.
